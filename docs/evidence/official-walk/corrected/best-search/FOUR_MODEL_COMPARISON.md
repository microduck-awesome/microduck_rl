# 三个 V2 checkpoint 与官方 ONNX 的指标对照

统计：每种指令 20 秒，取第 2–20 秒平均，每种 12 次重复。V2 三电压 10.2/11.1/12.4 V；官方原机三电压 6.5/7.4/8.2 V，各电压 4 次。均使用 GPU0 物理仿真，保留原生命令延迟和配对 IMU 安装误差，不施加外力或机体随机化。

三个 V2 模型使用 V2 结构和 SC0090，官方 ONNX 使用原版结构和 XL330。不同物理平台，表格是各自平台上的行为对照，不能据此将策略本身作跨机器人优劣排名。
