# SC0090 V4 复审记录（2026-09-15）

6000 是现有 V2/V3 任务的训练预算；2000、12000 是文档里的预算示例。
它们不是收敛保证，也不控制升阶。V4 已取消继承 6000 的隐式默认值，启动训练
必须明确给出 `--agent.max-iterations`，单位为额外 PPO 更新次数。

补充前提：今天是在此前训练基础上启动。日志显示 V2 从行走 `model_4050.pt`
和起身 `model_3750.pt` warm start，保留学习器状态并清零轮数/课程时钟；
源策略已分别完成 4051、3751 次更新。行走 `model_5999.pt` 的优化器计数和
归一化样本数交叉核对为累计 10052 次更新。设计续训参数时必须分清累计训练
历史、当前任务计数和新阶段计数；“恢复全局计数”不能解释成自动补回旧 warm
start 清掉的历史。该设计约束已补入 `AGENTS.md` 和训练说明。

200 是可修改的评估间隔，目的是摊薄独立评估的时间开销。这是工程经验值，
没有必须取 200 的理论依据。默认 24 步/更新时，它对应每环境 4800 步，
实际评估还要等到检查点保存；启动日志会打印这些量。课程最低停留时间、
通过次数、保留能力与挑战成功率分别配置。参数及取舍见
[训练说明](sc0090-staged-training.md)。

## 发现与修复

| 问题 | 修复与验证 |
| --- | --- |
| 不支持的分布式模式在校验前可能进入父类的 NCCL 初始化等待 | 将单 GPU、预算和调度参数检查移到父类构造之前；测试确认不会进入初始化 |
| 检查点可能被读到半写入内容；校验与实际加载读取两次文件 | 同目录临时文件加原子替换；校验与加载使用同一份字节；同一运行目录只允许一个写入者，锁不等待 |
| 超时后的等待没有明确上限；中断时评估子进程可能遗留 | 独立进程组；超时、中断和退出均清理子进程组；回收等待有上限，回收失败保留检查点并停止训练 |
| 评估出错后旧的通过次数和资格可能保留 | 清除连续通过次数并使最新资格失效；报告校验和合格检查点保存完成后才提交升阶状态 |
| 最后一个平滑阶段完成时覆盖了入口基准 | 保留原基准，后续相同表现仍可通过，不要求每次评估再额外改善 1% |
| 保存时立即改变命令与奖励，而 PPO 已缓存旧观测 | 在下一次正常环境重置中应用新阶段；评估期间不改当前实时参数 |
| 手动重置失败环境会额外推进整个批次的观测延迟；重置后覆盖行走命令也可能读到缓存旧值 | 使用正常自动重置；固定命令在命令重置时写入，推扰在控制步内执行；真实 GPU 测试验证连续环境每步只推进一次观测缓冲 |
| 平滑统计包含失败后的重试和重置跳变；多个 seed 的 RMS 被直接取算术平均 | 仅统计首次 episode 的有效差分；RMS 按平方量汇总；起身延迟约束使用各 seed 中最大的 P95 |
| 重置后的第一步被按“力矩减零”收费；不同目标的站稳时间可能混用 | 首个力矩样本不计差分；姿态目标改变后重新计时；再次跌倒后需重新完成名义站稳才启用姿态命令 |
| 显式传入完整 load_cfg 时可能漏恢复独立的自适应学习率和下一轮编号 | 按 optimizer/iteration 加载标志分别恢复；加载前检查有限值、学习率和计数 |
| 自动重置可掩盖数值失败后的物理状态 | 额外检查终止管理器保留的 nan_state 标记；发生数值失败时评估无效，不能按普通跌倒比例放行 |

评估协议已升级为 3。旧 V4 协议 2 的评估基准不能与修正后的统计直接比较：
无基准的旧检查点可保留策略、优化器和阶段，但清除旧通过记录重新评估；
带旧基准的检查点会明确拒绝作为完整续训输入。V2/V3 专家导入、协议 3 的
V4 完整续训仍受支持。只加载 actor 进行播放或导出可使用旧 V4 文件，丢弃旧评估指标。

## 验证范围

完整测试集 **355 通过、1 跳过**；8 组 **64 环境 × 5 次 PPO 更新**的 GPU
冒烟训练通过。每组检查点核验确认优化器增加 100 步、观测归一化新增 7680 个样本、
每环境增加 120 步，且归一化 ONNX 输入/输出保持 61→14、输出有限。

测试日志和检查点核验记录位于 `logs/sc0090_setup/v4_review/`。
检查内容包括电机计算的 GPU 零容差对照、部分重置与 DR、检查点中断、进程超时
与回收、连续升阶门槛、观测延迟、PPO/优化器计数、归一化和 61→14 ONNX 推理。

高级阶段和升阶测试使用修改阶段元数据的测试夹具，目的是执行这些代码路径，
不表示策略已学会这些能力。错误的测试夹具阶段时间戳也被加载校验拒绝；
修正夹具后单独重新验证升阶。它们不能作为生产训练源。

电机 80 rpm 限制、PPO 数值算子和物理积分精度没有在此次修复中改写。
本次 GPU 验证在 L40 上完成；这些结果不能证明所有 GPU、驱动组合都绝无竞态、
死锁或数值问题，也不构成已学会高级姿态控制的结论。
