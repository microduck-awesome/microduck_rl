# SC0090 行走与起身视频 · 2026-09-15

打开[视频网页](../index.html)可观看 3 段并排对比和 17 段单独回放，支持 0.25× / 0.5× / 1× / 2× 播放。MP4 为 H.264、25 fps、原速，无自动重置，也未删去未成功动作。

- 行走使用 `model_3450.pt`，每种指令 32 个随机化环境，单次 12 秒。
- 起身使用 `model_3200.pt`，每种初始姿态 32 个随机化环境，单次 6 秒。
- 每段单片固定展示对应组的第一个样本，未按成功结果挑选。
- 保留任务工厂配置中的物理/观测随机化，测试中移除课程变更和外部推扰，固定头部/身体指令为零，策略输出使用确定性动作。
- 记录的是 MuJoCo Warp 仿真轨迹，渲染不重新执行动力学；不是实机拍摄。
- 这些视频对应上述固定检查点，是[失败案例专项续训](../sc0090-failure-finetune.md)前的基线记录。

## 行走速度

统计第 2–12 秒的机身坐标系速度，丢弃起步前 2 秒。

| 前进目标 | 实测机身前向速度 |
| --- | --- |
| 0.10 m/s | 基本不动 |
| 0.20 m/s | 0.176 m/s |
| 0.30 m/s | 0.293 m/s |
| 0.40 m/s | 0.348 m/s |

0.2 m/s 后退指令的实测约为 0.193 m/s；左右侧移目标 0.15 m/s，实测约 0.060 / 0.063 m/s。左右转向目标 0.6 rad/s，实测约 0.293 / 0.153 rad/s。

这些是机身前向速度，不是沿固定直线的净位移速度。当前存在方向漂移，0.2 / 0.3 / 0.4 m/s 前进指令沿初始世界 x 方向的平均净位移速度仅约 0.093 / 0.125 / 0.151 m/s。各组本次 12 秒内均为 32/32 未触发倒地判定，但这不代表跟踪方向准确。

## 起身耗时

站稳判定：躯干高度至少 10.5 cm、倾角至多 20°、线速度小于 0.15 m/s、角速度小于 1.5 rad/s、双脚接触地面，全部连续保持 0.5 秒。下面的耗时包含这 0.5 秒确认时间；统计成功样本的中位数，失败样本不算入耗时。

| 初始姿态 | 6 秒内站稳 | 成功样本中位耗时 |
| --- | --- | --- |
| 坐姿 | 31/32 | 0.88 秒 |
| 趴倒 | 32/32 | 0.90 秒 |
| 仰倒 | 0/32 | 本次未成功 |
| 仰倒带随机侧滚角 | 0/32 | 本次未成功 |
| 左侧倒 | 0/32 | 本次未成功 |
| 右侧倒 | 0/32 | 本次未成功 |

初始姿态继承训练中的离地高度和关节扰动，不是摔倒后静置到完全平衡再开始计时。本次结果是小样本仿真测试，不能解释为所有实际跌倒的成功率。
