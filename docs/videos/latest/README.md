# 最新 SC0090 视频 · 2026-09-15

首页：[最新训练视频](../../index.html)。全部为预先录制的视频，访问 Pages 无需连接本地电脑。

- 行走 / 起身均使用 V4 `model_6400.pt`，从各自的 5999 checkpoint 保留状态续训 401 次更新。
- 14 段行走、转向与启停各 8 秒；五种起身各 4 秒；自由探索完整 60 秒。
- H.264、25 fps，播放时长对应真实仿真时长；不剪去未成功动作。
- 与本地模拟器相同的 CPU MuJoCo、SC0090 BAM、12 V、80 rpm、50 Hz 策略和归一化 ONNX；物理修订 2，已修正摩擦索引、摩擦公式和观测时序，关节速度观测延迟为 20 ms。
- 每个场景固定录制一次，使用标称参数，不做域随机化。不是随机化成功率测试或实机测量。
- 行走前后/侧向速度使用机器人朝向的水平坐标系，转向角速度使用机身 z 轴；恒定指令取第 2–8 秒平均。启动和停止在 2 秒切换指令，取第 3–4 秒平均。
- 0.03 m/s 保留为诊断场景，新增 0.08 m/s 对应当前纯行走训练最低目标；这不是实测舵机速度下限。
- 起身使用标准坐姿、俯卧、仰卧、左侧卧、右侧卧。站稳标准与模拟器一致，耗时包括 0.5 秒稳定确认。
- 自由探索每轮自动混合行走、扰动和五种姿态；视频明确标注姿态重置，之后由模型自行起身。
  采用序列编号 1、每段指令 4 秒、起身等待上限 12 秒。轨迹重置/扰动时间列在 JSON 中。

`video_validation.json` 记录全部 20 个 MP4 的解码、帧数、时长和 SHA-256 校验结果，共 4800 帧。
