## 共用部署契约

- 使用同一套已经确认支持V2/SC0090基线的运行程序，逐个导入ONNX并核对文件名和SHA；每次只激活一个起身策略。不能仅凭“3762”或相同ONNX元数据区分B/C。
- float32输入 `[1,61]`、输出 `[1,14]`，MLP无LSTM状态；50 Hz。ONNX内置归一化，运行端不再归一化。CAD HOME全零，action scale=1，连续角度目标；嘴部独立，不属于14维策略动作。
- 观测顺序：角速度3、重力方向3、关节位置14、关节速度14、上一动作14、twist3、head_pose4、body_pose6。起身基本测试将twist/head/body命令均置零；头部测试只写head_pose槽，其他命令保持零。不要把其他任务的posture标志写入twist槽。
- head_pose顺序：颈俯仰、头俯仰、头偏航、头侧倾，单位rad，按CAD关节坐标表达。四轴训练范围为 `±0.39 / ±0.39 / ±0.49 / ±0.11 rad`（约±22.35°/±22.35°/±28.07°/±6.30°）。这是训练指令范围，不替代机械限位或固件目标范围。
- 输出顺序必须完全一致：

```text
left_hip_yaw, left_hip_roll, left_hip_pitch, left_knee, left_ankle,
neck_pitch, head_pitch, head_yaw, head_roll,
right_hip_yaw, right_hip_roll, right_hip_pitch, right_knee, right_ankle
```

- 三者电机训练契约相同：SC0090 v5，P15/D30/I0，训练参考电压档10.2/11.1/12.4 V，goal profile清零。ONNX通用的joint_stiffness/damping元数据不是固件P/D寄存器值，不能据此改写实机增益。
- 训练输出未加动作滤波。实机对比保留同一套已验证的EMA、电压补偿、反馈处理与发送时序，不为某个策略单独开关或重复叠加。历史3762参考实机设置为：头目标EMA 0.5、腿0.7，11.1 V参考补偿，电压滤波1 Hz/EMA α=0.1；倍率`11.1/clamp(V_filtered,9.0,14.25)`。这是历史参考，不是本次自动下发的参数；当前固件/运行栈若不同，先记录并对三者保持一致。

## 控制比较条件

固定同一台机器人、外壳/电池/负载、足底和地面、零位/方向/IMU外参、机械及固件目标限位、固件与运行程序版本。记录实际整机质量、电压、温度及配置摘要。不要给A/B改配重去凑600.94 g；三个策略在同一台当前实机上比较。

每轮使用同一初态摆放方式和视频机位，模型顺序轮换 `A→B→C`、`B→C→A`、`C→A→B`，降低电压与温度随时间变化的偏差。电压明显变化则补测同一组，而非只补测失败模型。每次切换先停止当前策略，再经现有运行栈重新开始独立试次；确认上一动作/滤波等运行状态按同一规则初始化。不要在跌倒过程中热切换权重，也不要把测试HOME回零误当作只清空qpos的仿真重置。

A/B同时有训练日程、配对误差启用时点和单/双GPU差异；B/C有质量/惯量与GPU设备差异。因此这是整条策略的实机表现比较，不能单凭胜负归因于某一个因素或认定更新数越多越好。

## 分步测试

1. **导入与零指令筛查**：核对SHA、61D/14D、关节顺序、50 Hz和命令归零。由操作者确认支撑后短时启动，检查方向、突跳、抖动、反馈与目标是否一致。每版独立测试，模型导入成功不代表动作合格。
2. **起身**：先每类1次筛查，再对可继续的项目每模型累计10次。初态分为站立、坐姿、俯卧、仰卧、左侧卧、右侧卧、指定倾角初态；最后一类固定并记录角度/方向，不把手摆姿态当成与仿真frontier完全等价。每次最多8秒，命令全零，记录是否自行站起、首次站稳时间、是否先倒后起、再跌倒/碰撞/抖动。左右侧必须分开统计。
3. **站稳保持**：起身后继续全零命令30秒，单独记录身体倾斜、位移、抖动、头偏移与再跌倒。恢复成功的操作判据为8秒内双足站起且连续保持至少0.5秒、无人工扶持；仿真完整判据还包含倾角≤20°、线速度<0.15 m/s、角速度<1.5 rad/s，缺乏测量的项明确记“未测”，不能把人工观察通过直接写成同一仿真判据通过。
4. **头部响应与回零**：先单轴±0.04 rad、再±0.10 rad（头侧倾最高仍为0.10），通过后扩到各轴训练范围。每条命令用2秒零指令→2秒目标→2秒回零，正负方向各至少5次；单轴通过后再测固定的两轴及四轴组合。统一记录首动延迟、是否到达目标、末0.5秒角度误差、回零残差，以及躯干/足部是否失稳。缺乏校准外部角度测量时，编码器反馈误差须明确标注，不能冒充物理角度误差。
5. **HOME/再启动**：用三者相同的现有HOME流程，记录目标回读、实际姿态、到位时间、是否顶限，以及再次启动策略是否突跳。每模型至少5次。HOME、策略零命令站立是两个项目，分别记录。

先完成训练范围内测试。+63°颈部等超训练范围指令不属于基础对比通过条件；如单独测试，必须另列为范围外探索，并使用同一运行限位与受控支撑，不能混入训练范围均值。

任何持续顶限、强烈抖动、机械干涉、失稳、过热或固件故障，应立即停止当前项并保留失败记录。初态即失稳、人工扶持及提前停止都计入尝试总数，不悄悄删除后重测到成功为止。

## 已知仿真短板与记录方式

三版各自训练模型下恢复评测均曾达到1792/1792，但A/B使用600.94 g模型、C使用624.6 g模型，这不是三版在同一个模型上的统一排名，更不是真机成功率。

- A：训练范围外的大颈部指令误差仍明显，追加到6804不代表全范围更好。
- B：既有仿真中+63°颈部case的16次试验有7次在指令窗口出现高度<8cm或倾角>45°；均值角度误差不能掩盖身体失稳。
- C：在624.6 g模型上+63°颈部误差约14.41°，旧原始3762对照约10.44°；162条逐种子头部case、共1296次试验中，初始0–2秒零指令窗口有102次低姿态，2–4秒阶跃与4–6秒回零窗口均未出现该类低姿态。最大记录关节越限约3.75°，发生在初态阶段。故不能把起身通过率解释为全程站稳或机械安全已验收。


最终按模型×初态/指令分别汇总成功/总尝试、耗时中位数及最慢值、站稳保持、头部正负响应/回零、HOME以及失败类型。没有实际测量的项填“未测”。实机选择由这套同条件数据决定，不能只凭A/B/C编号、训练更新次数或仿真reward判断。
