# 3762 新碰撞版训练结果（2026-10-24）

已修正后背和左右凸起碰撞，并完成一个从随机初始化训练的新模型。最终累计 6804 次更新，两个 GPU 同步训练同一策略，每卡 4096 环境，全局 8192；两卡最终网络、归一化与优化器状态逐项一致。原 3762 权重保持原样。

## 模型与碰撞

基于 rise_baseline_paired3762 的完整冻结源码；原始 340 个 src 文件中仅 robot.xml 发生变化，新增 32 组同 CAD 来源的外壳凸分块。原有 XML 元素、质量 0.600941825 kg、质心和惯量保持不变。接触沉降检查验证后背和左右外壳支撑，最终壳体接触穿透约 0.05–0.28 mm。新增几何不额外增加质量。

## 训练过程

先完成新碰撞下的起身课程，再沿同一策略完成原头部阶段 1、2、4。为修复正向颈部欠响应，增加一段原阶段 2 的大指令巩固，再用原阶段 4 收尾；未引入新的奖励公式或物理参数。配对误差随机化从本轮初始化即启用，而历史 3762 在后期才切入，因此不是历史随机轨迹的逐步复现。首次双卡训练在 500 次评测后遇到归一化 inference tensor 同步错误；已修复并从各卡保存状态恢复，跨三次评测边界的实际批量复验通过。恢复采用原生新 episode，不声称物理轨迹无缝继续。

## 同一新碰撞模型下的对比

两条策略使用相同最终恢复阶段、原有两个开发种子、每类每种子 128 样本，8 秒无自动重置；这些不是独立留出种子，也不是实机成功率。通过判据要求末段稳定起身，不代表全过程没有下蹲或跌倒；示例的随机站立初态也有短暂姿态调整后恢复。

## 文件与复现

最终检查点：head-final/formal/rank0/resume_006804.pt（rank1 独立保存同一模型及自己的 RNG/课程状态）。ONNX 含归一化，61D 输入、14D 输出；66 个数值样本与训练网络比对最大差 1.04e-6。详细哈希、完整逐例报告和训练状态见 docs/evidence/rise3762-collision/final。保留所有中间检查点及失败证据。

独立的每类一个样本回放仅用于观察姿态变化，不替代 1792 次正式评测。回放直接渲染 GPU 仿真记录的 qpos，不重新积分不同物理模型。
