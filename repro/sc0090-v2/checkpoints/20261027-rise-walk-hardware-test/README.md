## 共同部署契约

- 使用现有已验证的 V2/SC0090 运行程序，按文件名和SHA选择模型，不依赖可能显示为`local`的ONNX运行名。一次只激活一个策略，切换沿用运行端现有停机/初始化流程。
- float32输入`[1,61]`、输出`[1,14]`，无循环隐藏状态，50Hz。归一化已包含在ONNX内，运行端不要再次归一化。
- 四款元数据均为14关节CAD HOME全零、`action_scale=1.0`。CAD零位需要当前V2舵机方向、编码器零位和IMU外参映射，不能把它当作未标定的舵机编码器0。
- 观测顺序为角速度3、重力3、关节位置14、关节速度14、上一动作14、twist3、head_pose4、body_pose6。命令区从第48维开始；起身A/B/C的13维命令全部置零。步行D仅写twist的`vx,vy,yaw_rate`，头/身体命令先保持零。
- C没有外部头部指令验收；头部四个动作仍参与起身与平衡，不锁头、不把网络头部输出置零。
- 输出关节顺序必须完全一致，嘴部独立于14维策略：

```text
left_hip_yaw, left_hip_roll, left_hip_pitch, left_knee, left_ankle,
neck_pitch, head_pitch, head_yaw, head_roll,
right_hip_yaw, right_hip_roll, right_hip_pitch, right_knee, right_ankle
```

- 保持当前已验证的SC0090固件增益、机械/固件目标限位、反馈处理、发送时序和电压补偿。训练电机参考为SC0090 V5、P15/D30/I0、goal profile清零，电压档10.2/11.1/12.4V；ONNX的通用stiffness/damping数值不是舵机P/D寄存器值。
- 训练输出没有动作EMA；实机现有滤波、限幅和电压处理应固定并记录，不为某个模型单独调整后再混合比较。

## 真机测试顺序与记录

固定同一台机器、外壳/电池/负载、足底和地面、零位/IMU标定、固件及运行程序版本。记录电压、温度、实际质量和运行参数。起身三款顺序轮换A→B→C、B→C→A、C→A→B，使用同一机位和初态摆放方法。

1. **静止与起身。** 每款先零指令站立20秒；再测试站立、坐姿、趴地、低姿态过渡、左侧躺、右侧躺、仰躺，每类10次。分别记录8秒内恢复、12秒内恢复、首次站立时刻、首次站立IMU三轴角速度与模长、随后连续3秒保持及最后站立状态。首次站立用双足支撑和躯干倾角回到20度内判定，不先用角速度筛掉高角速首帧；另记倾角4度内/角速0.35rad/s内的严格保持。起身过程贴限位只记录，站稳后14关节持续顶限位列为异常。
2. **后向及四向后推。** 先从0.05–0.10倍实际体重的短推开始，再逐步扩展到0.15/0.20/0.25倍。使用测力计时，`F=比例×实机质量kg×9.81`，记录实际施力位置、方向和完整力波形。持续时间采用0.20、0.32、0.50、0.60、0.80、1.20、1.60秒分档，逐级测试。每次从独立站稳初态开始，只施加一次力；下一次至少间隔10秒且重新站稳。后向优先，再同强度测前/左/右，各条件至少10次。没有测力计的手推仅作定性记录，不填入同一N×秒定量表。
3. **区分抗扰动与重新起身。** 从施力到恢复站稳期间始终不倒、无非脚撑地才记抗扰动成功；倒后再次站起单列为恢复成功，不抵消这次失稳。释放后继续记录首站IMU、连续3秒站稳和14关节实际反馈。
4. **步行D。** 零指令站立后，按`vx=0.10/0.15/0.20/0.30/0.40m/s`渐增测试，再测后退`-0.10m/s`、侧移`vy=±0.10m/s`、原地转向`yaw_rate=±0.50rad/s`及`vx=0.15m/s`组合转向。每档20秒、前2秒作为过渡，至少3次；记录实际位移、转角、偏航漂移、足部滑移及头/腿是否停在限位。0.10m/s不走是已知待核问题，不直接改增益或用更大命令掩盖。
5. **起身接步行。** A/B/C各自在恢复并连续站稳3秒后接D，先给`vx=0.15m/s`走10秒，再零命令保持3秒，各5轮；按运行端现有策略切换流程记录动作衔接和反馈，不临时增加插值或滤波。

建议每次保存一条CSV/JSON记录：模型编号与SHA、初态/指令、力比例/N/时长、实际电压/温度、是否全程不倒、非脚触地、最终恢复、首次站立时间、IMU三轴及模长、3秒保持、站稳后14关节近限位情况、视频和原始日志路径。连续顶限位、电机持续过载或明显卡死时，按现有急停/人工保护流程终止该次，保留失败记录，不用再次起身覆盖失败。
