# 6804 与 7000：暂停时选定的抗扰动模型

2026-10-28 按用户要求交付两条支系现有完整评审记录中保留的候选。目录包含两个原样 ONNX 和本说明，均内置各自检查点的观测归一化。训练目标仍暂停；本次只做文件核对与 CPU 推理一致性检查，没有重新训练、运行仿真电池或连接机器人。

两者均为实验候选，完整抗扰动目标尚未通过。7000 的非零头控跟踪存在退化，动态纠偏仍有越限；这些问题随模型保留披露。
