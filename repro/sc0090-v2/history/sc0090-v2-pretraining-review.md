## 2. PPO超参数：本轮设置、作用与演化

已核实官方基点 `b02fdea`：行走和起身均为24步、5个epoch、4个minibatch。以下依据实际 rsl_rl 5.0.1 代码，不把其它训练器的行为套过来。

| 参数 | 初始设置 | 对训练的影响 / 允许怎样调整 |
|---|---|---|
| 环境数 N | **基线8192；完整P0432768** | 8192是初始值；P048192约6.42万/s，32768实测10.76万/s后采用。影响覆盖、batch和更新频率，不是纯执行优化；两分支不混合梯度 |
| rollout步数 T | **24** | 50 Hz下每个片段0.48 s；episode不因此重置。影响GAE片段、自举依赖和更新频率；24是官方/历史起点，尚非V2实证最优 |
| 每更新样本 B | **基线196,608；P04 786,432** | 对比同时报告交互、优化次数和时间；继承旧N的消耗单独累计，不回乘新N。课程时钟仍是实际per-env步数 |
| minibatch数 | **4** | 基线每批49,152，P04每批196,608；保持20次Adam/更新但不是等样本优化频率，必须用实际学习效果复核 |
| 学习epoch | **5** | 每批数据复用5次，总20次Adam步骤/更新；这份实现不会因KL过高提前停止epoch。历史3epoch试验不构成普遍更优证据 |
| 优化器 | **Adam，actor+critic共用一个optimizer** | 不能把旧手写训练器的两个Adam直接套用。保留optimizer状态；warm start与resume区分 |
| 初始学习率 | **1e-3** | 步长过大可能超调/破坏能力，过小可能停滞；不因大batch机械线性放大 |
| 自适应学习率 | **adaptive，desired_KL=.01** | 实际每个minibatch：KL>.02则lr÷1.5，0<KL<.005则lr×1.5；范围[1e-5,1e-2]。记录实际lr，不把desired_KL当硬上限 |
| PPO clip | **.2** | 限制概率比代理目标中的激励；不保证真实KL一定小。配合实际KL、clip_fraction、行为退化判读 |
| gamma | **.99** | 50 Hz下约2 s折扣尺度（不是硬时域）；决定延迟收益重要性，不因T改变就随意更改 |
| GAE lambda | **.95** | 对TD残差做时间加权，影响偏差/方差；`gamma×lambda=.9405`，较远残差权重快速衰减；长动作仍通过价值自举学习 |
| 优势归一化 | **整个rollout归一化** | 非每minibatch归一化；必须在全局均值/方差之前拒绝非有限值，不能把坏advantage/return清零后继续学 |
| value loss系数 | **1.0** | 决定critic相对优化强度；看EV、原始回报方差与MSE，不单看loss大小 |
| clipped value loss | **True，clip=.2** | 以旧V(s_t)限制价值预测变化；禁止用终端V(s_{t+1})替换transition.values，否则破坏此基准 |
| entropy系数 | **.01** | 从零探索保留；历史熵=0曾导致不会起步。技能成熟后才允许有对照地下调，检查转向/头部/恢复是否遗忘 |
| 初始动作std | **每关节1.0，14个状态无关std参数** | 官方 `std_type="scalar"` 并非14关节共用一个标量。过大有饱和/冲击/反馈故障风险，过小会失去发现能力；记录各轴std与目标饱和率 |
| 梯度裁剪 | **1.0** | 实现分别对actor和critic裁剪；记录裁剪前后范数，不能用强裁剪掩盖错误回报 |
| 网络 | **61→512→256→128→14，ELU；critic 74→同隐藏层→1** | 先保留历史/官方规模；没有证据时不扩容。critic特权状态不进入actor |
| 观测归一化 | **actor/critic开启** | ONNX必须烘焙；每步更新次数不增不减。记录更新前的归一化漂移对KL的贡献，不能误归因优化步 |
| 对称增强、RND、动作EMA | **关闭** | V2多个关节方向不同；不盲用旧镜像表，也不引入部署端没有的动作滤波 |
| 控制/物理频率 | **50/200 Hz** | 固定dt/decimation，不靠改变物理精度换FPS；反馈100 Hz和20 ms查询延迟保留 |

PPO是先采样、再对同批数据进行多轮minibatch优化的方法；clip限制的是代理目标。[PPO原论文](https://arxiv.org/abs/1707.06347)。GAE的lambda控制优势估计的偏差/方差权衡，不能当作机器人动作持续时间。[GAE原论文](https://arxiv.org/abs/1506.02438)。上述具体数值和自适应分支来自本地锁定实现。

**调参顺序**：先查数据/时序/奖励符号→实际命令曝光和能力→课程门槛与阶段→精度项是否对误差有足够梯度→再根据KL/裁剪/EV/熵证据调整PPO。每次固定父检查点与交互预算，优先单变量；保留失败支路，不能只按reward选末端模型。

T=32/48的对照只能在正确且达吞吐要求的24步基线之后做：N固定时B变为262,144/393,216；同交互预算下更新次数减少、每样本仍复用5次但Adam步骤总数减少。要共同报告结果与wall time，不能归因成“仅采样更长”。
