# V2 策略训练路线比较

更新：2026-10-16T18:14:18+08:00。用户明确要求重新比较学习效率。“P04可训练/吞吐达标”不构成“所有技能默认P04从零”的证据。之前基线预训练路线提前搁置，路线结论撤回。

默认待验证候选为：基线掌握动作 → 有效随机化与量化适应 → 完整P04续训与验收。现有P04从零模型、失败模型、原始曲线和耗时全部保留作对照。最终P04策略目标不缩小；基线起身/站立仍保留独立比较候选，其它技能的基线预训练现在纳入授权范围。

比较以完整P04统一指标为终点，记录从随机初始化到首次达到该指标的整条路线总耗时。基线端reward高、低MSE或高吞吐都不能代替迁移结果。未达标在固定预算结束标为未达标，不按最后点loss排名。

| 阶段 | 定义与用途 | 继续条件 |
|---|---|---|
| B0 动作基线 | 同V2 CAD、HOME、v5电机/50Hz/200Hz/61→14；连续关节目标与明确记录的官方观测噪声/延迟，学习动作；不是P04执行器或传感器仿真 | 用相同物理动作指标检查是否学会，保留所有失败与有限预算 |
| B1 有效随机化/量化 | 加入已验证native-count映射/限位/限速、时延与v5实测误差；效力需完整P04交叉评测确认 | 量化边界/观测时刻/重置契约通过；不将P04观测偷偷换真值 |
| B2 完整P04 | 原S0/O0/R1、有效尖峰不去除、真实故障保护；明确normalizer/optimizer/课程迁移，统一验收 | 相同动作、健康姿态、头控/相机指标及同seed未见测试 |
| 对照 | 已有P04从零完整曲线；新增对照只在确有缺口时给固定预算 | 区分历史研发成本与同一冻结配方的可重放路线成本 |

预算按技能累计，三阶段合并，不因换名称重新计时/归零。分别记录训练、验证/评测、导入/构建/保存、排队时间与GPU秒；主指标为无排队的端到端首次达标时间，同时报告实际墙钟。各阶段N/T/epoch/minibatch与实际Adam步、命令曝光、课程难度要记录，防止仅用交互数量掩盖优化剂量差异。

优先准备一个尚未解决的非起身技能验证路线，先复用GroundPick的已验证物理目标、reset、原评电池和完整P04对照；正式前锁定基线定义、源差异、各段预算与同一终点。不会先给全部技能各开一条无界基线。暂缓尚未开始的Roulade64k外置教师诊断：已取消等待worker/CPUwatcher，实际0仿真/0PPO，源码和CPU证据保留。

当前Ground精度正式段及Sit已完成训练的末评继续收尾，防止丢弃已有有效预算。基线路线是否更快、对哪些技能更优，仍待实测，尚不声明赢家。无轮滑、无P4/host/Web部署，实机未测试。
